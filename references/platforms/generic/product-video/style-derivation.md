# 风格推导：从内容推出画面，而不是从模板里挑

用户给你的是主题、数据或一次更新。**它不是风格**。这一页把「内容特征」推成「本片的视觉系统」，顺序固定、每步都要留下文字依据，最后固化成一份只有本片用得上的风格单元。

顺序：**信息形状 → 运动语言 → 性格滑块 → 单帧主构成 → 不变量与禁令**。

三步之内不许写代码。写不出依据的那一步，说明内容还没读懂，回去读 [影片方向](direction.md) 第 2 节。

---

## 1. 先判信息形状（它决定运动语言，比品类更决定）

**关键判断：决定运动语言的是「这条信息是什么形状」，不是「产品是什么品类」。** 同一个数据产品，讲「它能做什么」和讲「注册率为什么翻倍」，该用两套完全不同的语言。按产品品类套风格，是这类片子千篇一律的根因。

| 信息形状 | 听起来像 | 首选运动语言 | 选错会变成 |
|---|---|---|---|
| **主张 Claim** | 「我们做了 X」「任何模型都能跑」 | 动态排版、生成场、3D 物件 | 一次功能巡游（观众不知道你想说什么） |
| **流程 Workflow** | 「输入这个，得到那个」 | 光标演示、连续变形 | 抽象形状里没有产品 |
| **机理 Mechanism** | 「它为什么能工作」 | 系统图、机理动画、平面世界 | 一堆快切（讲不了因果） |
| **证据 Evidence** | 「注册率翻了一倍」 | 数据叙事、编辑拼贴 | 数字一闪而过（看不懂，也没有出处感） |
| **清单 List** | 「这次更新五件事」 | 章节化排版、模块网格、卡牌蒙太奇 | 五张等权幻灯片 |
| **转变 Transformation** | 「改版前后」 | 连续变形、分屏对比 | 两张静图之间硬切 |
| **故事 Story** | 「一个 agent 醒了过来」 | 角色、手绘、实拍素材主导 | 要点罗列 |
| **展示 Showcase** | 「看它能做什么」 | 一件深做的作品、能力集锦 | 一份功能清单 |

**一支片子可以有两种形状**（故事开场 → 流程中段 → 主张收尾）。只有当**切换本身有意义**时才换语言，否则一条语言走到底。

写下你判定的形状与依据。内容跨两类时，写明哪一段是哪类、切换点在第几秒。

---

## 2. 再从语言表里选一到两条

下面十种覆盖产品片几乎全部需要。**选一到两条**：一条主语言，一条只在某一小段使用的辅助。多于两条，片子会散。

| 语言 | 它在说什么 | 适合 | 实现要点 | 常见失败 |
|---|---|---|---|---|
| **光标演示** | 它真能用，是这样的 | 功能、工作流、SaaS、Agent | 真实组件 + 真实点击/输入，光标落在拍点 | 点完没有状态变化；用的是手画的假界面 |
| **连续变形** | 一套被精心设计过的系统 | 界面功能、循环、sting | 一个对象贯穿，形变成下一个 | 中间态很丑；中途换物 |
| **动态排版** | 一个有分量的主张 | 口号、清单、钩子、收尾 | 字本身就是主角，字号跨数量级 | 每个元素同一种入场 |
| **模块网格** | 精确、被工程化 | 开发者工具、基础设施、规格 | 严格栅格、等距、对齐 | 网格密到看不清 |
| **数据叙事** | 这是证据，它变了 | 指标、报告、里程碑 | 先问后画；落点标注；来源行 | 柱子不从零；坐标中途换刻度；数字停留 < 1 秒 |
| **机理** | 为什么它能工作 | AI/ML、算法、科学 | 一步一步推演，每一步都能看懂 | 快切代替因果 |
| **系统图** | 这些部分怎么连起来 | 基础设施、Agent、流水线 | 节点 + 连线逐段生长 | 为了凑满而虚构节点 |
| **平面世界** | 惊奇、尺度感 | 科普、解释性内容 | 简化世界 + 镜头穿行 | 缩略图尺度下看不清 |
| **卡牌蒙太奇** | 一步一步，做完了，是真的 | 小团队产品、消费类 | 每拍一张卡落定 | 每张卡停留太久变成字幕 |
| **角色** | 情绪、人格 | 故事、消费类、Agent 拟人 | anticipation → action → follow-through | 物体平移冒充表演 |

**锚定规则**：语言必须能指出它对应产品的哪一点。选择理由写成「因为产品有 X，所以用 Y」。写不出 X 的，删掉。

与 [视觉手法词汇](visual-vocabulary.md) 的关系：那一页是**手法**（怎么做），这一页是**语言**（用什么做、在说什么）。先定语言，再从词汇里挑 3–5 个手法。

## 3. 用五个滑块定参数（只调参数，不换语言）

从**证据**给每一轴打分 −2…+2。证据指：官网字体、文案语气、配色、产品界面密度、既有宣传物料。**形容词不算证据**。

| 滑块 | −2 | +2 | 它影响什么 |
|---|---|---|---|
| 精确 ↔ 俏皮 | Linear、Vercel、Stripe | Duolingo、Figma | 缓动（硬缓出/线性 ↔ 带回弹的弹簧）、形状语言（栅格 ↔ 圆胖） |
| 冷静 ↔ 活力 | Notion、冥想类 | 游戏、体育、音乐 | 节拍（80–100 ↔ 125–150 BPM）、镜头长度、切点密度 |
| 高端 ↔ 平易 | Apple、奢侈、Leica | 工具类大众产品 | 留白、字号对比、颜色数量、一屏多少东西 |
| 技术 ↔ 人文 | CLI、基础设施、模型 | 社交、健康、儿童 | 等宽/代码/图表 ↔ 照片、人脸、手绘 |
| 老牌 ↔ 新锐 | 银行、企业 | 初创、beta 发布 | 克制与延续 ↔ 大胆、意外 |

写成一句话，作为后面所有选择的依据：**「精确、冷静、高端、技术、新锐。」**

**三条纪律**：

- 「精确 ↔ 俏皮」管运动与形状，「高端 ↔ 平易」管密度与词汇——**不要让它俩互相拖动**。
- 「冷静 ↔ 活力」主要管配乐与剪辑，**剪辑比配乐更决定观感**。
- 冷静不等于慢：很多冷静的片子节奏不快（BPM 77–130），但**切得勤**。要「科技感 / 酷」，用混合路线，不要用「更慢的缓动」去假装高端。

滑块与第 2 节的关系：滑块**不改**语言选择，只改语言的参数。同一套语言，+2 与 −2 是两支完全不同的片子。

## 4. 单帧主构成（画面里只有一个视觉核心）

动起来之前先定「任何一帧停下来都成立」的构图。**一张只允许一个一级视觉核心，最多配一到两个辅助线索。**

| 主构成 | 一句话 |
|---|---|
| 电影静帧 | 事情刚发生或即将发生，主体不看镜头 |
| 巨型文字结构 | 标题承担空间压力 |
| 单一物件隐喻 | 围绕一个物件组织（钥匙、号码牌、棋盘、证件） |
| 极端人物裁切 | 局部特写，尺度压迫 |
| 负空间小人物 | 主体只占 5%–20%，空间说话 |
| 空间秩序 | 透视、对称、重复门洞或队列形成权力结构 |
| 临场视角 | 镜头像角色的眼睛，允许手、门框、遮挡物进入前景 |
| 群像分层 | 核心 / 关系 / 背景三层，有站位逻辑 |

写清楚：主体与主体尺度、画面重心与视线动线、前景中景背景关系、标题与主体的遮挡关系、信息区划分（顶部 / 中部 / 底部）。

**从参考图提取的是视觉 DNA，不是构图**：构图秩序、画面密度、主体尺度、色彩结构、光线性质、字体尺度、字图关系、影像质感、信息层级。**不提取**：人物关系、动作、场景骨架、道具组合、标题字形与位置、完整配色。参考图默认不作为生成输入，除非用户明确要求编辑某一张具体图片。

## 5. 固化为风格单元：五条不变量 + 三条禁令

推导完写进 `DIRECTION.md` 的「画面规范」之前，先写这一小块。它是**本片**的，不是通用的，也不进任何库。

```
### 本片风格（只有本片适用）
信息形状：Evidence（注册率为何翻倍）
主语言：数据叙事 + 模块网格（仅开场 3 秒）
辅助语言：动态排版（只用于收尾主张）
性格：精确、冷静、高端、技术、新锐

不变量（一眼可辨的五条）
1. 底色近黑偏冷，绝不用纯黑
2. 所有数字用等宽，且只出现一次
3. 强调色只有一个琥珀色，只给「被测量到的东西」
4. 网格线永远 8% 对比，不抢数据
5. 每屏只有一个结论

禁令（本片绝不做）
1. 不用弹跳缓动
2. 不出现多色渐变
3. 不用无出处的大数字铺满屏幕
```

**禁令比不变量更重要。**「做什么」容易记住，「不做什么」才是让片子保持气质的东西——跑偏通常不是做少了，是多做了。

---

## 6. 自检：推导是否成立

- 拿掉产品名，这套视觉还站得住吗？站得住说明推导太泛，回到第 2 节的「因为产品有 X」。
- 把元素换成另一个领域的名词，会不会也成立？会成立说明是模板，重来。
- 五个滑块能否各自指出一条证据？指不出说明在凭印象。
- 禁令里有没有一条是「为了不像上一支片子」而定的？至少有一条应来自**反重复**（见 [影片方向](direction.md) 第 5 节）。

推导结果写进 `DIRECTION.md`，并同步进 `plan.json` 的 `styleDerivation`（字段契约见 [两级内容路由](../../../core/routing.md) §7.2）。
