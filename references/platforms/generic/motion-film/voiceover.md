# 配音：优先 edge-tts，按内容选音色，绝不用系统机器音

配音是片子「像不像完成品」的分水岭之一。这一页定三件事：**用什么引擎、怎么选音色、什么时候停下来问用户**。

适用于全部片型（`product` / `evidence` / `explainer` / `story`）与全部平台形式。用户已经提供配音或明确指定音色时，直接照办，不套用本页的优先级。

---

## 1. 优先级链（严格按序）

| 顺序 | 来源 | 什么时候用 |
|---|---|---|
| 0 | **用户提供的录音或指定音色** | 用户明确给了 → 直接用，不再往下走 |
| 1 | **微软 edge-tts** | 默认首选。免费、无需 API key、中文自然度好、参数可控 |
| 2 | **其他免费 TTS**（本机已装的、可离线运行的） | edge-tts 不可用（无网络、区域限制、被墙）或没有合适音色 |
| 3 | **停下来问用户** | 上面都不成立时 |

**第 3 步是必须的，不是可选的。** 停下来时说明：为什么前两级都不可用、还有哪些路（用户自己录音 / 用户指定一个能访问的 TTS 服务 / 改成无配音版），让用户决定。**不要自己降级到机器音。**

---

## 2. 绝对不用：系统自带机器音

以下一律不用，即使片子会因此没有配音：

- macOS `say`（`say -v Tingting`、`say -v Meijia` 等）
- Windows SAPI（`System.Speech`、PowerShell `Add-Type -AssemblyName System.Speech`）
- eSpeak / Festival / `pico2wave` 这类拼接式合成器
- 任何听起来像「导航播报」的音色

理由：这些音色的韵律平、断句硬、没有情绪，一开口就把片子拉到「演示品」档次。**没有配音优于机器音**——静音片 + 精良画面，比机器音旁白更专业。

> 这条替代了旧版 [本机实测管线](pipeline-notes.md) 第 11 条里「macOS `say -v Tingting`」的用法。那一条现在只保留后半句的经验：**长台词超窗口时优先扩该幕时长，而不是加速语速**。

## 3. 用 edge-tts 之前

```sh
# 检查是否可用（3 秒超时，不要让它卡住整个流程）
python3 -c "import edge_tts; print(edge_tts.__version__)" 2>/dev/null || echo "edge_tts not installed"
```

未安装时先问用户是否允许安装（它需要联网 pip 安装、且合成时需要联网）：

```sh
pip3 install edge-tts        # 约 40KB，纯 Python
```

**edge-tts 的两个约束要提前告诉用户**：

1. **合成需要联网**（微软在线服务）。完全离线的机器用不了。
2. 部分地区可能访问不稳定；失败时不要疯狂重试，按第 1 节落到第 2 级。

音色清单随时可查：`edge-tts -l`（会实时拉取，需要网络）。

---

## 4. 按主题内容选音色

**先定「声音性格」，再挑音色名。** 声音性格来自 [影片方向](direction.md) 的五轴性格与 [风格推导](style-derivation.md) 的第 3 步——与画面同源，不要独立拍脑袋。

### 4.1 性格 → 音色特征

| 片子气质 | 性别倾向 | 语速 | 音高 | 语言地区 |
|---|---|---|---|---|
| 技术、精确、B 端 | 中性偏女或沉稳男声 | −3% ~ +2% | 默认 | 大陆普通话为主 |
| 发布、有力量、造势 | 男声为主 | +2% ~ +8% | −2Hz ~ 0 | 大陆普通话 |
| 科普、解释、可信 | 中性 | −2% ~ +3% | 默认 | 大陆普通话 |
| 温暖、人文、故事 | 女声为主 | −6% ~ −2% | 默认 | 大陆或台湾普通话 |
| 活泼、消费、轻快 | 年轻女声或男声 | +5% ~ +12% | +2Hz ~ +6Hz | 大陆普通话 |
| 沉稳、纪实、严肃 | 深沉男声 | −8% ~ −3% | −3Hz ~ −1Hz | 大陆普通话 |

### 4.2 候选音色（以 `edge-tts -l` 实际输出为准）

下面是一份**起点清单**，不是固定答案。选之前一定先 `edge-tts -l` 看当前可用的 `ShortName`，微软会增删音色；清单里没有时按 4.1 的特征去挑。

| 语言区 | 参考音色（ShortName） | 声音特征 |
|---|---|---|
| 普通话（大陆） | `zh-CN-XiaoxiaoNeural` | 女声，自然、亲和，默认首选之一 |
| 普通话（大陆） | `zh-CN-YunxiNeural` | 男声，年轻、轻快 |
| 普通话（大陆） | `zh-CN-YunjianNeural` | 男声，沉稳有力，纪实/宣传 |
| 普通话（大陆） | `zh-CN-YunyangNeural` | 男声，播音腔，正式播报 |
| 普通话（大陆） | `zh-CN-XiaoyiNeural` | 女声，活泼、年轻 |
| 普通话（大陆） | `zh-CN-YunxiaNeural` | 男声，偏少年感 |
| 普通话（大陆） | `zh-CN-liaoning-XiaobeiNeural` 等 | 东北等方言区，仅当内容本身需要地域感 |
| 台湾 | `zh-TW-HsiaoChenNeural` / `zh-TW-YunJheNeural` | 女 / 男，台湾腔 |
| 香港（粤语） | `zh-HK-HiuMaanNeural` / `zh-HK-WanLungNeural` | 女 / 男，粤语 |
| 英语 | `en-US-AriaNeural` / `en-US-GuyNeural` | 女 / 男，通用 |

**选音色的三条纪律**：

1. **语言跟着文案走**，不是跟着人设走。中文文案配普通话，粤语地区内容才用粤语，中英混排只读中文部分。
2. **一条片子一个音色**，不中途换人。需要「多人对话」时，先确认用户真的要两个角色，否则一律单播。
3. **音色要能被说清理由**，写进 `plan.json` 的 `voiceover`：因为气质是「沉稳纪实」，所以选湿润度低的男声、语速 −5%。

### 4.3 参数怎么调

| 参数 | 建议范围 | 说明 |
|---|---|---|
| `--rate` | −10% ~ +12% | 超过 ±15% 会明显失真；**提速不要超过 +12%**，需要更快就砍文案 |
| `--volume` | +0% | 响度交给 [混音](audio-and-qa.md) 的 `loudnorm` 处理，这里不要预调 |
| `--pitch` | −4Hz ~ +6Hz | 只做微调；大幅变调会发闷或发尖 |

**语速与文案长度是一对联动的数字**：语速 +12% 还念不完的句子，是文案太长，不是语速不够——回到 [分镜、文案与节奏](story-and-copy.md) 砍字。旧管线第 11 条讲的就是这件事。

## 5. 生成与落盘

```sh
# 单条配音 + 自带字幕
python3 <skill-dir>/scripts/video-line/make_voiceover.py <video-dir>/plan.json \
  --voice zh-CN-YunjianNeural --rate=-5% --pitch=-2Hz
```

脚本做的事：检查 edge-tts → 按 `plan.json` 的 `voiceover` 或命令行参数选音色 → 逐幕生成 → 输出 `assets/voice/vo.wav`（或分段）与 `assets/voice/vo.srt` → 写入 `evidence/voiceover.json` 记录音色、参数、时长。

**必须做的三件事**：

1. **听一遍**。机器生成不等于可用：多音字、数字读法（「2026」读成「二零二六」还是「两千零二十六」）、英文缩写（「API」）都可能错。
2. **逐句核对转写**：把生成音频再转文字（本机有 whisper 就用），定位读错的字，改文案后重生成。
3. **对齐到拍**：配音时长决定镜头停留，不是反过来。[节奏单](rhythm-brief.md) 的文字停留规则优先。

`plan.json` 里记录：

```json
"voiceover": {
  "engine": "edge-tts",
  "voice": "zh-CN-YunjianNeural",
  "rate": "-5%",
  "pitch": "-2Hz",
  "reason": "气质沉稳纪实，选湿润度低的男声，语速略降",
  "source": "generated"
}
```

`source` 取值：`user-recording`（用户提供）/ `user-specified`（用户指定音色）/ `generated`（本页生成的）/ `none`（无配音）。

## 6. 落不到第 1、2 级时怎么问用户

不要含糊地说「配音有问题」。给三个具体选项，让用户挑：

> 这台机器上 edge-tts 用不了（原因：……），也没有找到其他可用且合适的免费 TTS。三个方案：
> 1. 你提供一段录音（我按它做逐字对齐）；
> 2. 你指定一个有权限访问的 TTS 服务，我来接；
> 3. 改成无配音版（配乐 + 音效 + 字幕），通常比机器音更专业。
>
> 我建议 3 或 1。你选哪个？

问完就停，不要边等边用 `say` 顶上。

---

## 7. 与其他分册的关系

- 音色性格来自 [影片方向](direction.md) 与 [风格推导](style-derivation.md) —— 配音不是独立决策。
- 配音时长回写 [节奏单](rhythm-brief.md) 的文字停留。
- 混音与响度交给 [混音与验收](audio-and-qa.md)（配音默认听着清楚，music ducking 让位）。
- 无配音时的处理写进 `plan.json` 的 `audioExceptionReason`（沿用既有硬约束）。
