# 微信官方规格总表 wechat-specs

本文件是微信三线所有**硬参数**的单一事实来源，机器可读版本为 `scripts/social_specs.json`（自检脚本与模板都从它读，不要在别处硬编码）。

**使用规则**
- 带来源链接的条目 = 官方文档明确写过，可以直接当红线用。
- 标注「以编辑器实际提示为准」的条目 = 官方口径不一致或随版本变化，**不得当确定值使用，不得编造**。
- 平台规则会变。每次产出前如果距上次使用超过 3 个月，重新核对一遍来源页。

## 一、公众号图文消息（长文）

| 项 | 规格 | 来源 |
|---|---|---|
| 标题 | 必填，**≤64 字**，不支持换行与自定义字号 | 微信服务市场《公众平台图文消息编辑方法》 |
| 作者 | ≤8 字 | 公众号后台编辑规范 |
| 摘要 | ≤120 字；不填时系统自动抓取**正文前 54 字** | 《公众平台图文消息编辑方法》 |
| 正文 | 必须含文字，**≤50000 字**；单次群发最多 8 条内容 | 同上 |
| 正文字号 | 后台工具栏仅三档（小/标准/大）；内联 `font-size` 通常保留，**以手机预览为准** | 实测共识，非官方明文 |
| 正文图片数量 | ≤500 张 | 2025 版平台参数汇总 |
| 图片格式 | `bmp` / `png` / `jpeg` / `jpg` / `gif` | 《公众平台图文消息编辑方法》 |
| 单图大小 | **≤10MB**（封面与正文同） | 同上 |
| 正文图片建议尺寸 | 大图建议 **900×500**；上传后自动压缩为**宽 640px** 缩略图，手机端可点开原图 | 同上 |
| 静态图清晰度建议 | 宽度 1080px，PNG-24 | 平台参数汇总 |
| GIF 建议 | 宽度 640px，帧率 12–20 | 平台参数汇总 |
| **头条封面** | **2.35:1**，推荐 **900×383px** | 平台参数汇总（与官方后台一致） |
| **次条及以上封面** | **1:1**，推荐 **500×500px**（旧的 200×200 规格仍在部分入口使用） | 同上 |
| 内容内视频封面 | 16:9，1920×1080（在播放页展示） | 同上 |
| 已发布修改额度 | 每篇可改 3 次；标题改 3 字、正文改 120 字、图片 3 张、视频 1 个（公众号后台视频，视频号视频不支持） | 腾讯客服 FAQ |
| 群发频率 | 订阅号每天 1 次；服务号每月 4 次 | 平台规则 |

> **头条标题压封面**：单独推送一条时，标题显示在封面**下方**；推送两条及以上时，头条标题会**压在封面图上**。做封面时必须在标题区留出低干扰区域，否则标题不可读。

### 正文 HTML / CSS 白名单（关键约束）

公众号后台会对粘贴内容做安全清洗，**保留什么、丢掉什么是可以提前设计的**：

| 类别 | 支持 | 说明 |
|---|---|---|
| 保留标签 | `p` `section` `span` `strong`/`b` `em`/`i` `u` `br` `blockquote` `ul`/`ol`/`li` `h1`–`h6` `table` 系列 `img` `a` | 结构标签基本保留 |
| 微信专有标签 | `mpvoice`（语音）、`mpvideo`（视频） | 音视频必须用它们，普通 `audio`/`video` 无效 |
| 内联 `style` | 常用属性基本保留：`color` `background-color` `font-size` `font-weight` `font-style` `text-align` `line-height` `letter-spacing` `text-decoration` `margin` `padding` `border` `border-radius` `box-shadow` `opacity` `display` `vertical-align` | **样式必须写在标签的 `style` 属性上** |
| `<style>` 块 | ❌ 剥离 | 无法用 class 选择器、伪类、媒体查询 |
| 外链 CSS / `<link>` | ❌ 剥离 | |
| `<script>` | ❌ 屏蔽 | 视为非法内容 |
| `@media` / `@keyframes` | ❌ 无效 | 无法做响应式与动画；响应式改用 `vw`/`vh` |
| `position: relative/absolute/fixed` | ❌ 过滤 | 布局只能走标准文档流；`z-index` 随之失效 |
| `id` 属性 | ❌ 剥离 | 页内锚点跳转失效 |
| `class` 属性 | ⚠️ 保留但无样式作用 | 只对第三方编辑器识别结构有用 |
| `<iframe>` / `<form>` / `<input>` / `<object>` / `<embed>` | ❌ 不支持 | 交互与表单不可用 |
| 图片 `src` | **必须用微信素材库地址**（`https://mmbiz.qpic.cn/...`）；外链与 Base64 不显示 | 先在后台「素材管理」上传，再替换 `src` |
| 单位 | 优先 `px` / `vw` / `vh`；`%` 做高度或位移常不生效 | 稳妥优先 px |
| `float` | ⚠️ 慎用 | 可能脱离容器导致意外显示 |
| 事件属性（`onclick` 等） | ❌ 剥除 | |

**推论（写模板时必须遵守）**：交付的正文必须是**一段内联样式的 HTML 片段**，不含 `<style>`、不含外链图片、不依赖 `class`、不使用 `position`。模板里的图片 `src` 一律写占位符，交付时提示用户替换为素材库地址。

## 二、公众号图片消息（微信图文 / 小绿书）

| 项 | 规格 | 来源 |
|---|---|---|
| 形态 | 用户**横滑浏览**全部图片，展示比例 **3:4**；系统自动生成封面图 | 微信官方（2023-03 订阅号助手升级说明） |
| 图片数量上限 | 订阅号助手端 **≤20 张**；部分入口/版本为 **≤9 张** | 口径不一致 → **以编辑器实际提示为准** |
| 推荐张数 | 6–9 张（超过 9 张完读率明显下降） | 实务经验，非官方 |
| 推荐图片尺寸 | **3:4**，推荐 **1080×1440px** | 平台参数汇总 |
| 单图文字上限 | 「文字生成图片」功能：每张图文字 **≤2000 个** | 微信官方（2023-03-15） |
| 单图文字建议 | ≤60 字（超过就拆张） | 实务经验 |
| 单图大小 | **≤10MB** | 微信官方（与文章样式一致） |
| 动态图 | 单图 ≤10MB，**总帧数 ≤300 帧** | 同上 |
| 格式 | jpg / jpeg / png / bmp / gif；**不支持 live 图** | 同上 |
| 标题 | ≤64 字（可长可短） | 平台参数汇总 |
| 交互 | 支持分享、收藏、在看、点赞；图片可带二维码/小程序码，发布后支持长按识别 | 微信官方 |
| 修改额度 | 每篇可改 3 次：标题改 3 字、正文改 120 字、图片 3 张内可替换/删除 | 腾讯客服 FAQ |
| 内容数量上限 | 图片 500 张、视频号视频 10 个、视频/音频各 10 个、音乐 20 首、小程序 50 个 | 平台参数汇总 |

**列表展示规则**（决定封面怎么做）：
- **≥3 张图**时，消息列表显示前 **3 张缩略图，裁成 2.35:1**。
- **≤2 张图**时，统一使用**首图，裁成 16:9**。

→ 所以：想发 3 张以上时，**前 3 张都要能各自成立**且关键信息落在中心区（避免 2.35:1 裁切切掉标题）；想发 1–2 张时，首图要按 16:9 的中心安全区设计。

## 三、视频号视频

| 项 | 手机端 / 视频号助手 | 来源 |
|---|---|---|
| 视频格式 | 暂不支持 HDR，其他不限 | 微信视频号帮助中心《视频号发表的素材有什么要求》 |
| **宽高比** | **0.33 ~ 3.0**；官方**建议用标准比例 16:9 或 9:16** | 同上 |
| 时长 | 手机端 **3 秒 ~ 60 分钟**（较旧机型 30 分钟）；助手端 **3 秒 ~ 8 小时** | 同上 |
| 体积 | 手机端 **≤2GB**；助手端 **≤20GB** | 同上 |
| 码率 | 建议 **≥10Mbps**，在体积允许下越大越清晰（导 1080P 及以上即可） | 同上 |
| 分辨率 | 建议 **1080p 及以上** | 微信服务市场官方答复 |
| 编码 | H.264 与 H.265(HEVC) 均支持；**H.265 在 Windows Chrome/Edge 上不能播放**，需装 HEVC 扩展或用 Mac Safari 上传 | 帮助中心 |
| 竖版封面 | **1080×1260px（6:7）** | 平台参数汇总 |
| 横版封面 | **1080×608px（16:9）**；但**主页列表会自动裁成 6:7** | 同上 |
| 直播封面 | 810×1440px | 同上 |
| 描述文字 | **≤1000 字**；超过三个非空白行会**自动折叠** | 帮助中心 |
| **短标题** | **≤16 字**；描述 >16 字时才出现短标题输入框；会出现在**搜索 / 话题 / 活动 / 地点 / 订阅号消息**等场景 | 帮助中心 |
| 图片形式 | 手机端 **≤9 张**，助手端 **≤18 张**；**不支持 live 图和 GIF**；宽高比 0.33~3.0 | 帮助中心 |
| 发布频率 | 每天可发多条，不限次数 | 平台说明 |
| 可挂载 | 描述里可加话题 `#xx#`、@提及、位置定位、**公众号文章链接** | 平台说明 |

**横版的坑**：横版视频在视频号主页展示时，封面比例被自动改成 6:7，**封面上的文字信息容易错位**。稳妥做法二选一：
1. 横版素材加黑边做成竖版（不影响观感），封面按 1080×1260 竖版设计；
2. 保留横版，但**单独做一张 1080×1260 竖版封面**，关键信息全部落在 6:7 的中心安全区。

## 四、跨端共用的媒体素材规则

> 以下是**微信视角**的汇总。跨平台通用的媒体与编码标准已上提到 [`core/pipeline.md`](../../core/pipeline.md) §4；两边若有出入，以 `core/pipeline.md` 为准。

| 项 | 规则 |
|---|---|
| 视频编码（全平台稳妥） | `H.264` + `yuv420p` + `-movflags +faststart`；与视频线第 71 行的 ffmpeg 命令一致 |
| 音频 | AAC，192kbps；响度沿用视频线第 21 条（`loudnorm` 到 I=-15 / TP=-1.5，显式 `-ar 44100`） |
| 图片色彩 | 微信生态统一用 sRGB；不投 HDR |
| 图片体积 | 每张 ≤10MB（公众号与图文线）；视频号图片形式单张上限另计，以编辑器提示为准 |
| 字体 | 一律系统字体栈（`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`）。需要特殊字体就做成图 |
