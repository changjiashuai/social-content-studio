# 小红书规格总表 xiaohongshu-specs

本文件是小红书两种形式的**人读**硬参数总表，机器可读版本为 `scripts/social_specs.json` 的 `platforms.xiaohongshu` 节点（自检脚本与模板都从它读，不要在别处硬编码）。

> ⚠️ **来源质量**：小红书**没有**像微信开放文档那样的公开素材规格文档。下表以**创作服务平台 / App 编辑器的实际提示**为主，辅以第三方汇总。
> **带「口径不一」的行不是确定值**：交付时必须写成"以编辑器实际提示为准"，不得编造精确数字。平台规则会变，距上次核对超过 3 个月请重新验证。

## 一、图文笔记（`xiaohongshu/image-text`）

| 项 | 规格 | 来源 |
|---|---|---|
| 图片比例 | 竖版 **3:4**（推荐 **1080×1440**）、方形 **1:1**（1080×1080）、横版 **4:3**（1080×810） | 第三方汇总 |
| 比例一致性 | **整篇笔记只能用一种比例**，混用会在滑动时跳版 | 第三方汇总 |
| 图片数量 | 多数资料：**≤18 张**（2024 年由 9 张扩容）；部分入口/旧口径：**≤9 张** → **口径不一，以编辑器实际提示为准** | 第三方汇总 |
| 推荐张数 | **6–9 张**（过少显薄，过多完读率下降） | 实务经验 |
| 图片格式 | **JPG / PNG**（不支持 GIF 与动图） | 第三方汇总 |
| 单图体积 | **≤20MB** | 第三方汇总 |
| 最小分辨率 | 建议单张**不低于 720×960**，否则信息流里发虚 | 第三方汇总 |
| 标题 | **≤20 字**；前 10–12 字是钩子（列表页会截断） | 第三方汇总 |
| 正文 | **≤1000 字**；建议 **100–400 字**；前 2–3 行是推荐与搜索的抓取重点 | 第三方汇总 |
| 话题标签 | 建议 **5–15 个**（部分口径上限 10 个）→ **口径不一** | 第三方汇总 |
| 封面 | **首图即封面**，需单独排版；信息流可能按更窄比例裁切，关键信息留中心 | 第三方汇总 |
| 修改额度 | 笔记可编辑；**违规记录不会因删除而消除** | 平台规则 |

## 二、视频笔记（`xiaohongshu/video`）

| 项 | 规格 | 来源 |
|---|---|---|
| 视频比例 | **9:16 竖屏最佳**（1080×1920）；也支持 3:4、1:1、16:9 | 第三方汇总 |
| 时长 | **≤15 分钟**（部分口径 60 分钟）→ **口径不一，以编辑器提示为准** | 第三方汇总 |
| 推荐时长 | 30 秒–3 分钟（短视频更易获推荐） | 实务经验 |
| 格式 / 编码 | **MP4 / MOV**；**H.264 + AAC** | 第三方汇总 |
| 体积 | 网页端单文件较大（有 4GB 的说法），App 端更严 → **口径不一** | 第三方汇总 |
| 帧率 | 25–30 fps | 第三方汇总 |
| 分辨率 | 建议 ≥1080p（最低 720p） | 第三方汇总 |
| 封面 | **单独做 3:4 竖版（1080×1440）**，不要用视频首帧 | 第三方汇总 |
| 标题 | **≤20 字** | 第三方汇总 |
| 正文 | **≤1000 字**；建议 50–200 字 | 第三方汇总 |
| 话题标签 | 建议 **5–15 个** | 第三方汇总 |
| 前 3 秒 | 决定完播，钩子必须在开头 | 实务经验 |
| 编辑页可设封面 | 可从视频截帧，也可上传自定义图片 | 第三方汇总 |

## 三、平台红线

| 类别 | 禁止 | 后果 |
|---|---|---|
| **站外导流** | 微信号、"vx/vxin"、"加我"、二维码、其他平台链接 | 限流、内容下架，严重时封号 |
| **绝对化用语** | "最便宜""绝对有效""100%有效""根治"等（广告法风险词） | 限流、审核不通过 |
| **搬运** | 直接搬运他人图片/视频，原创度不足 | 系统 MD5 + 语义识别比对，判违规 |
| **水印/白边** | 图片带其他平台水印，或加白边 | 影响推荐、触发审核 |
| **效果宣称** | 医疗、金融类的效果承诺（"7 天瘦 10 斤"） | 高危违规 |
| **拼音代字** | 用拼音或错别字替代平台不允许出现的词 | 判违规（且不视为规避成功） |

> 自检脚本会对 `meta.json`（`title` / `body` / `topics`）与 `copy.md` 做**风险词扫描**，命中报 WARN。
> 扫描是**提示**不是判定——"微信"可能出现在正常语境（如"同步到微信"），需要人工确认是否构成导流。

## 五、与微信规格的对照（做跨平台内容时看这里）

| 维度 | 微信 | 小红书 |
|---|---|---|
| 驱动方式 | 订阅关系（打开率） | 发现 + 搜索（点击率 + 话题） |
| 图文比例 | 3:4（图片消息） | 3:4（可 1:1 / 4:3，整篇统一） |
| 单图体积 | ≤10MB | ≤20MB |
| 图文张数 | 6–9 推荐（上限口径不一） | 6–9 推荐（上限 18，口径不一） |
| 长文载体 | 公众号长文（≤50000 字） | 无长文形式，正文 ≤1000 字 |
| 视频封面 | 6:7（1080×1260） | 3:4（1080×1440） |
| 视频编码 | H.264 优先 | H.264 + AAC |
| 外链 / 导流 | 图片消息不支持；正文限白名单域名 | **严格禁止站外导流** |
| 文案语气 | 可专业、可长 | 必须口语、个人视角、短 |
