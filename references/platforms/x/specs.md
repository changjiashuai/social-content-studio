# X 规格总表

**本表的每一条都要能说清来源。** X 未公开一份完整的 Article 官方规格文档，很多数字来自公告与实测汇总——凡属此类，标 `uncertainty` 并给 `safeMax`（稳妥值），交付时写成「以编辑器实际提示为准」。

来源质量分级：

| 标记 | 含义 |
|---|---|
| `x_official` | X 官方公告/帮助中心/官方账号指南，可靠性最高。<br>本文档主要依据 [@XCreators「The ultimate guide to Articles on X」](https://x.com/XCreators/status/2011957172821737574)（2026-01-16） |
| `x_third_party` | 第三方汇总与实测，**可能与实际有出入**，一律带 `uncertainty` |
| `practice` | 本包实务经验，不是平台规则 |

---

## 1. Article（长文）· `x/article`

### 1.1 正文长度

| 项 | 值 | 来源 | 说明 |
|---|---|---|---|
| 字符上限 | **约 100,000 字符**（约 15,000 词） | `x_third_party` | 多个第三方来源一致，但 X 未在公开帮助页给出固定数字 → 带 `uncertainty` |
| 稳妥上限 | **75,000 字符** | `practice` | 留出编辑器计数口径差异的余量；超过此值先在本地计数核对 |
| 建议长度 | 800 – 3,000 词 | `practice` | 长文完读率在这个区间最好；超过 5,000 词需要非常强的结构支撑 |

### 1.2 标题与封面

| 项 | 值 | 来源 | 说明 |
|---|---|---|---|
| 标题 | 必须有；建议 30–70 字符 | `practice` | 太短无信息量，太长在卡片上被截断 |
| 封面图 | 支持；建议 **16:9（1200×675 或 1600×900）** | `practice` | 时间线卡片按横版取景 |
| 摘要 / 副标题 | 编辑器支持一段引导文字 | `x_third_party` | 没有独立摘要字段，**第一段就是摘要** |

### 1.3 内容能力

| 能力 | 支持 | 备注 |
|---|---|---|
| 分节标题（H1/H2） | ✅ | 结构的主要手段 |
| 粗体 / 斜体 / 删除线 | ✅ | 大量使用会显得嘈杂 |
| 有序 / 无序列表 | ✅ | 步骤与清单用它 |
| 缩进 | ✅ | 引用段落用它 |
| 图片 | ✅ | 多图可横排；单图建议 ≥ 1200px 宽 |
| 视频 | ✅ | 走 X 原生上传，与 Article 共用配额 |
| GIF | ✅ | |
| 嵌入帖子 | ✅ | 引用某条 X 帖作为证据 |
| 外部链接 | ✅ | 卡片预览依赖目标页的 OG 标签 |
| 自定义 HTML / CSS | ❌ | 只能通过编辑器可视化排版 |
| 粗体 | ✅ | 官方建议**几乎每节都加粗关键洞察**（用于扫读，不是克制使用的装饰） |
| 小标题 | ✅ | 官方建议**每 3–5 段**一个小标题 |
| 段落长度 | — | 官方建议**每段 2–4 行**为上限 |

### 1.4 账号与发布

| 项 | 值 | 来源 | 说明 |
|---|---|---|---|
| 发布权限 | **所有 Premium 订阅者**均可发布 | `x_official` | 官方原话：「We've recently expanded access to **all Premium subscribers**」；不需要 Premium+ |
| 编辑已发布文章 | 支持（与帖子编辑机制类似） | `x_third_party` | 编辑权益与订阅等级相关 |
| 文章列表 | 个人主页有独立 Articles 标签页 | `x_third_party` | 便于长期检索 |

### 1.5 发布形态（免费 / 订阅者可见）

官方明确支持两种可见范围：

| 形态 | 发布路径 | 用途 |
|---|---|---|
| 公开 Article | Publish | 增长与传播，主力形态 |
| **订阅者可见** | Publish → 「Choose your audience」选 **Subscribers** → 再次 Publish | 订阅变现 |

订阅者可见文章在**非订阅者**推广时用付费墙链接：

```
https://x.com/YOURUSERNAME/creator-subscriptions/subscribe
```

订阅资格在 **Creator Studio** 查看。来源：`x_official`。

## 2. 与其他形式的关系

- X **长帖**（约 25,000 字符、无标题）不在本包范围内。需要「一条说完」时用它，不要硬塞进 Article。
- 与公众号长文相比：X Article 更适合**对外传播 + 可被引用**，公众号更适合**私域沉淀 + 完整论证**。多平台同做时，论证最完整的那份做事实源。

## 3. 校验方式

```sh
python3 <skill-dir>/scripts/check_social_delivery.py \
  --project <content-dir> --forms x/article --strict
```

会核对：正文与标题长度、封面比例、图片体积、`meta.json` 结构、以及是否有可追溯主张（内部溯源见 [provenance](../generic/motion-film/provenance.md)）。
