# X（Twitter）平台包

**平台 ID**：`x` ｜**定位**：长篇公开写作与传播的主阵地之一

X 有两种「长」的东西，容易混：

| | 长帖（Long post） | **Article（文章）** |
|---|---|---|
| 形态 | 时间线内直接展开的连贯长文 | 独立页面，点击后才打开 |
| 上限 | 约 25,000 字符 | 约 100,000 字符 |
| 结构 | 无标题、正文连续 | 有标题、封面、分节标题、列表、图片 |
| 收录 | 不单独成页 | 进个人主页 Articles 标签页，可长期检索 |
| 适合 | 一条说清的完整观点 | 有论证结构的长内容：复盘、教程、深度分析 |

**本平台包只做 Article**。需要「一条说清」的短内容，用长帖而不是 Article——两者入口与阅读场景不同，不要混用。

## 平台共性

- **门槛**：Article 需要**付费订阅**（Premium 级，不是必须 Premium+）。发布前确认账号有权限。
- **入口即点击**：Article 不在时间线内展开，用户要先点开。所以**开头第一段承担全部钩子责任**——它同时是时间线里的摘要。
- **格式是真能力**：标题、分节标题、粗体、斜体、删除线、缩进、有序/无序列表、图片、视频、GIF、嵌入帖子都支持。写到能用到这些不等于都该用，见 `article.md`。
- **中英文混排**：正文用系统字体栈渲染，不加载外部字体。需要特殊字体时把那段做成图。
- **话题标签不流行**：X 的 `#` 习惯与小红书完全不同，正文里堆标签会显得外行。有限使用或不用。

---

## 平台红线

- **不发布无法溯源的事实性主张**。X 的引用与社区笔记机制会让错误迅速被指出；每条数据按 [内部溯源](../../platforms/generic/motion-film/provenance.md) 记入 `evidence/FACTS.md`。
- **不虚构引用**：不伪造他人言论、不伪造截图、不伪造数据来源。
- **不站外导流堆砌**：可以放链接，但正文不要写成「关注我 / 私信我 / 加群」的导流稿；X 对纯导流内容的分发不友好。
- **搬运需标注**：转载他人内容要给出处与授权状态。
- **涉及金融、医疗、法律的效果宣称属高危**，与其他平台一致。
